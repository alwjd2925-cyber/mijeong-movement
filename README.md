# 미정 클래스 — 웹사이트 시안 v1

`@mi.jeong_k` 핸드스탠드 · 요가 클래스의 시안입니다.
화이트 베이스 위에 **화이트 · 솔리드 블랙 · `#F3FF00`** 세 색만 쓰는 **벤토 그리드** 레이아웃입니다.
큰 라운드 코너(20~28px) 카드와 면 대비로 구분하고, 1px 직각 선은 최소한만 남겼습니다.
포인트 컬러는 `styles.css` 맨 위 `--butter` 값 하나로 바뀝니다(`--butter-2`는 호버용).

색은 모두 `:root` 변수로만 잡혀 있습니다.

| 용도 | 변수 | 값 |
| --- | --- | --- |
| 전체 바탕 | `--paper` | `#F6F7F5` |
| 카드 · 패널 | `--surface` | `#FFFFFF` |
| 한 단계 들어간 면 | `--surface-2` / `--surface-3` | `#F3F4EF` / `#E9ECE5` |
| 톤 블록(수업 그림) | `--paper-2` | `#EEF0EA` |
| 본문 글자 | `--ink` | `#141518` |
| 보조 글자 | `--ink-70` / `--ink-45` / `--ink-25` | `#4F535C` / `#63666E` / `#8C919C` |
| 솔리드 다크 카드 | `--dark` + `--on-dark` | `#141518` + `#FFFFFF` |
| 다크 카드 위 보조 글자 | `--on-dark-70` / `--on-dark-45` | 흰색 78% / 58% |
| 선택 · 포인트 | `--butter` + `--on-butter` | `#F3FF00` + `#141518` |
| 선 | `--line` / `--line-strong` | `#E6E8E2` / `#D5D8D0` |
| 경고(라이트) / 경고(다크) | `--warn` / 다크 카드 안 `--warn` | `#8A5300` / `#FFD24A` |
| 서브 포인트 | `--blue` | `#136CFC` — 체크박스 포커스 링에만 |

- **옐로 카드**(`#F3FF00` 바탕) 위 글자는 반드시 `--on-butter`(거의 검정)를 씁니다.
- **다크 카드**(`#141518` 바탕) 안에서는 `--ink`/`--ink-70`/`--line` 같은 변수를 카드 안에서 흰 계열로 다시 잡아,
  그 안의 모든 요소가 자동으로 흰 글자를 쓰게 했습니다(`.track-panel`, `.pass`, `.warm-block`, `.reg-price`,
  `.state-banner.is-pending`, `.site-foot`).
- 블루는 화면 어디에도 배경으로 쓰지 않고, 키보드 포커스 링(`input.chk:focus-visible`)에만 남겼습니다.
- **체크 표시**: 상자(`.chk`, `.tick`)는 **채우지 않고 테두리만** 두고, 체크 표시에만 색을 넣습니다.
  다크 카드 위 = `#F3FF00` 체크, 라이트/옐로 카드 위 = `#141518` 체크. 선택 전후로 상자 크기·테두리 두께가 같아
  레이아웃이 흔들리지 않습니다.


## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 구조 + 인라인 SVG 라인 일러스트(sprite) + 영상/강사 모달 |
| `styles.css` | 디자인. 색·타이포·간격은 맨 위 `:root` 변수에서 한 번에 바꿀 수 있습니다 |
| `data.js` | ① 수업·시간표·시퀀스 콘텐츠 ② 예약·수강권 API(localStorage 어댑터) |
| `app.js` | 화면 그리기와 클릭 처리 (데이터는 전부 `api`를 통해서만 다룹니다) |
| `tests/api.test.js` | 예약·취소·강사 대리·온라인 체크 로직 테스트 (`node tests/api.test.js`) |

## 보는 방법

1. `index.html`을 브라우저로 열기 (파일 더블클릭).
2. 또는 이 폴더에서 `python -m http.server 8000` → `http://localhost:8000`.

폰트는 Pretendard(CDN) + Instrument Sans(Google Fonts)를 불러옵니다.
인터넷이 없으면 기기 기본 폰트로 보입니다.

## 자주 고칠 곳

- **수업 시간표**: `data.js` → `CLASSES[].slots` (`dow` 0=일 … 6=토, `start`/`end`는 `HH:MM`).
  여기만 고치면 예약 화면의 날짜 목록도 같이 바뀝니다.
  `CLASSES[].mode`는 `offline`(스튜디오) / `online`(온라인). 온라인 클래스는 `slots: []`로 두고
  `when` 문구로 안내합니다(예약 시간표에는 나오지 않음).
- **수업 소개 문구**: `CLASSES[].blurb` / `.note` (현재 문구는 초안입니다).
- **시퀀스**: `WARMUP`, `SEQUENCES.beginner`, `SEQUENCES.intermediate`의 `name` · `dose` · `cue` · `tags`.
- **영상**: 각 동작의 `video.youtubeId`에 유튜브 ID(`dQw4w9WgXcQ` 같은 11자리)를 넣거나,
  `video.url`에 주소(`https://youtu.be/...`)를 넣으면 모달에서 바로 재생됩니다.
  비어 있으면 "영상 준비 중"으로 표시됩니다.
- **수강권 규칙**: `CONFIG.passTypes` (1회권 30일 / 4회권 60일 / 8회권 90일).
  수업별 예외는 `PASS_VALIDITY` — `functional: { 1: null }` 로 **펑셔널 요가 1회권은 유효기간 없음**
  (만료 체크 없이 `expiresAt: null`).
- **금액**: `data.js` → `PRICES`. 오프라인은 `offlinePass[수업][권종]`(예: 핸드스탠드 8회권 300,000원,
  펑셔널 1회 35,000원 · 4회 120,000원 · 8회 200,000원), 온라인은 `online[수업].amount`
  (모빌리티 59,000원, 지난 얼리버드 49,000원은 `was`에 기록). 코칭은 `amount: 300000, weeks: 7`.
  금액이 아직 없으면 `null`로 두면 화면에는 `금액 추후 안내`로 나갑니다.
- **수업별 권종**: 어떤 권종이 있는지는 `PRICES.offlinePass[수업]`의 키로 정해집니다.
  핸드스탠드에 1회권 키가 없으므로 화면에서 1회권이 빠지고, 신청·승인·부여도 API에서 막힙니다.
  **수강권은 수업마다 따로**입니다 — 핸드스탠드 8회권 + 펑셔널 1회권처럼 각각 골라 합산하며,
  잔여 횟수도 그 수업의 예약에서만 차감됩니다.
- **온라인 클래스 동작**: `data.js` → `ONLINE.morning.movements`(모닝 모빌리티 8개 동작),
  `ONLINE.coaching.movements`(P3 시퀀스의 핵심 연습 8개). 여기에 `video`를 채우면
  체크표의 `영상 보기` 버튼에서 바로 재생됩니다.
- **수업 접근 권한**: `data.js` → 수강생의 `classes` 배열(아래 "수업별 접근 제어" 참고).
- **취소 마감**: `CONFIG.cancelDeadlineMs` (기본 1시간).
- **예약 가능 기간**: `CONFIG.bookingWindowDays` (기본 14일).

- **배포 캐시**: `index.html`의 `styles.css?v=…` / `data.js?v=…` / `app.js?v=…` 뒤 문자를
  배포마다 바꾸면 방문자 브라우저가 약 10분 캐시를 기다리지 않고 새 파일을 받습니다.

## 데모 계정

데모 버튼은 4가지 수업(핸드스탠드 · 펑셔널 · 모닝 · 코칭)을 골고루 확인할 수 있게 구성했습니다.

| 버튼 | 이름 | 코드 | 열린 수업 | 수강권 |
| --- | --- | --- | --- | --- |
| 신규 수강생 | 김하늘 | `MJ-1024` | 없음 | 없음 (→ `등록`) |
| 오프라인 수업별 수강권 | 이서연 | `MJ-2048` | 핸드스탠드 · 펑셔널 · 모닝 | 핸드스탠드 4회권 2회 남음 · 펑셔널 4회권 3회 남음 |
| 모닝 모빌리티 | 박지우 | `MJ-0812` | 모닝 | 없음 (온라인만) |
| 온라인 코칭 | 정민아 | `MJ-1125` | 핸드스탠드 · 모닝 · 코칭 | 핸드스탠드 8회권 5회 남음 |
| (로그인) | 최유진 | `MJ-0917` | 펑셔널 | 펑셔널 4회권 만료 (→ `재등록`) |

예약/수강권/노트 데이터는 `localStorage`(키 `mijeong.class.v1`)에 저장됩니다.
강사 모드 아래 "데모 초기화"로 처음 상태로 되돌릴 수 있습니다.
데모 데이터 구성이 바뀌면 `data.js`의 `version`을 올리며, 이때 저장된 데모 데이터는 새 구성으로 다시 시작합니다.

온라인 두 수업은 정해진 시간표를 지어내지 않고, 카드에 `온라인` 표시와 안내 문구만 두었습니다.

## 수강권 (수업별)

수강권은 **수업마다 따로** 발급되고 차감됩니다.

- 저장 구조: 수강생마다 `passes: { handstand: {...}, functional: {...} }` — 각각 `type · total · used · issuedAt · expiresAt`.
  `expiresAt: null` 이면 유효기간 없음(만료 체크 없음).
- **차감/복구**: 예약·취소·강사 대리 예약·대리 취소 모두 **그 수업의 수강권에서만** 1회가 빠지고 돌아옵니다.
  한 수업 수강권이 만료·소진되어도 다른 수업 수강권으로는 계속 예약할 수 있습니다(그 수업 행만 `수강권 만료`·`횟수 소진`).
- **화면**: 수강생 화면에 수업별 카드가 쌓이고(`핸드스탠드 무브먼트 4회권 — 2 / 4회 남음`, `펑셔널 요가 1회권 — 1 / 1회 남음 · 유효기간 없음`),
  상단 상태 줄과 강사 모드 수강생 목록에도 `핸드스탠드 2/4 · 펑셔널 3/4(유효기간 없음)`로 표시됩니다.
- **강사 모드**: `수강권 부여`에서 수강생을 고르면 그 수강생이 듣는 오프라인 수업별 선택이 나오고, 고른 수업만 새로 부여/교체됩니다.
- **예전 단일 `pass` 데이터**는 불러올 때 자동으로 수업별 `passes`로 바뀝니다.
  원래 수강권은 첫 번째 오프라인 수업이 이어받고(사용 횟수·유효기간 그대로), 나머지 오프라인 수업에는
  같은 권종·같은 유효기간의 수강권이 사용 0회로 붙습니다. 예전 신청서의 `passType`도 수업별 `passTypes`로 바뀅니다.

## 수업별 접근 제어

수강생은 `classes`에 들어 있는 수업의 화면만 볼 수 있습니다.

| 수업 id | 수업 | 열리는 화면 |
| --- | --- | --- |
| `handstand` | 핸드스탠드 무브먼트(오프라인) | 오프라인 예약(핸드스탠드 슬롯) + `#sequence` |
| `functional` | 펑셔널 요가(오프라인) | 오프라인 예약(펑셔널 슬롯) |
| `morning` | 모닝 모빌리티(온라인) | `#online`의 모닝 트래커 + 내 노트 기록 |
| `coaching` | 핸드스탠드 온라인 코칭(온라인) | `#online`의 코칭 트래커 + 내 노트 기록 |

- **비로그인**: 히어로 + 수업 소개(`#class`) + 로그인 박스만 보이고, 예약 시간표 · `#online` · `#sequence`는 숨김 (헤더 내비게이션은 `class` · `login`만)
- **오프라인 수업이 없으면**: 예약 시간표 대신 "온라인 클래스 수강 중" 안내만
- **온라인 수업이 하나면**: 탭 없이 프로그램 이름만, **둘 다면** 탭 전환
- **온라인 수업이 없으면**: `#online` 섹션 자체를 숨김
- **핸드스탠드를 듣지 않으면**: `#sequence` 숨김
- API도 같은 규칙을 지킵니다 — 수강하지 않은 수업은 예약할 수 없고, 수강하지 않은 온라인 클래스는 체크·노트를 저장할 수 없습니다.
- 강사 모드에서 **새 회원 등록**과 **수강생별 열린 수업**을 체크박스로 정하고 바꿀 수 있습니다(체크 즉시 저장).

## 신규 등록 · 수업 선택

수강생은 등록·재등록 신청 때 **듣고 싶은 수업을 직접 고릅니다(최소 1개, 여러 개 가능)**.

- `등록` / `수업 추가` / `재등록` 버튼을 누르면 신청 폼이 열리고, 네 수업이 오프라인/온라인 배지와 함께 체크박스로 나옵니다.
- **0개면 신청할 수 없습니다** — 신청 버튼이 잠기고, 그대로 제출하면 안내 문구와 함께 막힙니다(API도 `수업을 하나 이상 선택해 주세요.`로 거부).
- 체크는 폼을 다시 그리지 않고 그 자리에서 상태만 바꿉니다(레이아웃 밀림 없음).
- **오프라인 수업을 고르면 그 수업의 수강권을 따로 고릅니다.**
  `핸드스탠드 무브먼트`를 체크하면 핸드스탠드용(`4회권 180,000원` / `8회권 300,000원`),
  `펑셔널 요가`를 체크하면 펑셔널용(`1회권 35,000원` / `4회권 120,000원` / `8회권 200,000원`) 블록이 각각 나옵니다.
  두 수업을 함께 신청해도 **각각 원하는 권종을 고르며**, 예상 결제 금액은 두 금액의 합입니다
  (예: 핸드스탠드 8회권 + 펑셔널 1회권 → 335,000원). **온라인만 고르면** 수강권 없이 신청됩니다.
- 신청서에는 고른 수업 목록(`classes`)과 수업별 희망 수강권(`passTypes`)이 저장되고, 수강생 화면의 "확인 중" 배너에
  `핸드스탠드 무브먼트 8회권 · 펑셔널 요가 1회권`처럼 보입니다.
- 강사 모드 요청 목록에는 **신청 수업 · 수업별 희망 수강권 · 이미 열린 수업**이 함께 표시되고,
  수업별 수강권 선택(이미 쓰고 있는 수강권은 `그대로` 선택)을 확인한 뒤 승인하면
  **신청한 수업마다 그 수업의 수강권이 따로 발급**됩니다(이미 열려 있던 수업은 유지).
- 온라인만 신청한 건은 수강권 없이 승인합니다.

## 온라인 체크 트래커

`#online` 섹션에서 온라인 클래스를 주차별로 체크합니다.

- 탭: 수강 중인 프로그램만 (`모닝 모빌리티` / `핸드스탠드 온라인 코칭`)
- 주 선택: `3주 전` · `2주 전` · `지난주` · `이번 주` · `다음 주` (월요일 시작, 날짜 범위 표시).
  노트가 있는 주는 자동으로 선택지에 들어갑니다.
- 옆(모바일은 아래)에 `Mobility Note` / `Coaching Note` 입력 → `노트 저장`(포커스가 벗어나도 자동 저장)
- 체크 버튼은 체크 전/후 크기와 위치가 같습니다(기준선 정렬·굵기 변화 없음). 저장 중에도 흔들리지 않습니다.
- 기록은 로그인한 수강생별로 `localStorage`(`mijeong.class.v1` → `online[학생id][프로그램][주 시작일]`)에 저장
- 강사 모드의 `온라인 체크 / online` 블록에서 이번 주 학생별 체크 수와 노트를 모아 봅니다.

### 내 노트 기록 (My Notes)

체크표 아래에 로그인한 수강생이 쓴 노트를 **최신 주차 순**으로 모아 보여 줍니다.

- 카드: `주차 · 날짜 범위` / 그 주의 `N/M 동작 · K회 체크` / 노트 전문(줄바꿈 유지)
- 온라인 수업이 둘이면 노트마다 수업 이름 배지가 붙습니다.
- 카드를 누르면 그 프로그램·주차로 이동해 바로 수정할 수 있습니다.
- 저장하면 목록에 즉시 반영되고, 노트가 없으면 빈 상태 안내를 보여 줍니다.
- 데모 샘플: 이서연(모닝)에 3주치, 정민아(코칭)에 2주치 노트가 들어 있습니다.

## 확인해 볼 흐름

1. **수업별 화면** — 로그인 전에는 `class` · `login`만 보입니다. 데모 버튼 4개를 눌러 보면
   각 수강생에게 열린 섹션만 남는 것을 볼 수 있습니다(김하늘→아무것도 없음, 이서연→예약+시퀀스+모닝,
   박지우→모닝만, 정민아→예약+시퀀스+코칭·모닝 탭).
2. **신규 등록** — `김하늘` 선택 → `등록` → 수업 0개면 신청이 막히는지 확인 → `핸드스탠드 무브먼트`+`펑셔널 요가`+`모닝 모빌리티` 체크 → 수강권 블록이 수업별로 나오는지 확인 → 핸드스탠드 `8회권`·펑셔널 `1회권`을 각각 고르면 합계 335,000원 → `등록 신청` → 강사 모드 요청 목록에서 `핸드스탠드 무브먼트 8회권 · 펑셔널 요가 1회권 · 모닝 모빌리티`와 금액을 확인하고 `승인 · 개시` → 김하늘 화면에 수강권 카드 두 장과 예약 시간표, 온라인 탭이 함께 열립니다.
3. **수업 추가** — 이미 수업을 듣는 수강생의 `수업 추가`로 다른 수업을 더 신청하면, 기존 수업은 그대로 두고 신청한 수업만 더해집니다.
4. **재등록** — 최유진(`MJ-0917`)으로 로그인 → `재등록` → 만료된 `펑셔널 4회권`이 미리 골라진 채 폼이 열립니다 → 신청 → 강사 모드에서 승인.
5. **예약/취소** — `이서연`으로 핸드스탠드 날짜를 예약 → 핸드스탠드 카드만 2/4로 줄고 펑셔널 카드는 3/4 그대로 → 같은 자리 `취소`(마감 전)로 핸드스탠드만 3/4 복구.
5-1. **1회권 유효기간 없음** — 펑셔널 1회권을 받은 수강생은 `유효기간 없음`으로 표시되고 D-day가 없으며, 시간이 지나도 만료되지 않습니다.
6. **수업 접근 변경** — 강사 모드 → `수강생 · 수업`에서 박지우의 `핸드스탠드`를 체크하면
   그 수강생 화면에 예약 시간표와 시퀀스가 바로 열립니다.
7. **강사 대리 예약·취소** — `대리 예약`에서 수강생을 고르면 그 수강생이 듣는 수업만 시간표에 나옵니다.
8. **온라인 체크 · 노트** — `이서연`으로 로그인하면 `모닝 모빌리티` 이번 주 체크와 지난 2주 노트가
   `내 노트 기록`에 쌓여 있습니다. 칸을 눌러 체크/해제하고 노트를 저장하면 목록에 바로 반영되고,
   새로고침해도 그대로 남습니다. 노트 카드를 누르면 그 주차로 이동합니다.

## 아직 정해지지 않아 가정한 부분

- 취소하면 **그 수업의 횟수가 복구**됩니다(마감 전 취소 기준). 강사 모드의 대리 취소는
  마감과 상관없이 취소되고 횟수가 복구되지만, 이미 시작한 수업은 예약할 수 없습니다.
- 수강권을 새로 부여하면 **그 수업의 이전 수강권만 교체**되고 잔여 횟수는 넘어가지 않습니다
  (이미 잡힌 예약은 새 수강권에서 소진으로 계산). 다른 수업의 수강권은 그대로입니다.
- **펑셔널 요가 1회권은 유효기간 없음**으로 두었습니다. 다른 권종은 1회 30일 · 4회 60일 · 8회 90일입니다.
- **온라인 코칭은 7주 · 300,000원**으로 반영했습니다(수업 카드·금액표·온라인 프로그램 안내).
  실제 결제·진행 방식은 인스타 DM으로 안내하는 것으로 두었습니다.
- 수업 소개 문구와 큐잉 문구는 시안용 초안입니다. 실제 수업 언어로 바꿔 주세요.
- 수업 정원(자리 수) 개념은 아직 없습니다.

## 실제 운영 배포까지

1. **호스팅 (GitHub Pages)**
   - 이 폴더를 저장소에 올리고 Settings → Pages에서 배포, 또는 `gh-pages` 브랜치 사용.
   - 커스텀 도메인(`mijeong.com` 등) 연결 + HTTPS.
2. **백엔드 (Supabase 권장)**
   - 테이블: `students(id, name, code, created_at)`,
     `passes(id, student_id, class_id, type, total, used, issued_at, expires_at)` (expires_at null = 유효기간 없음),
     `sessions(id, class_id, starts_at, ends_at)`,
     `bookings(id, student_id, session_id, created_at, status)`,
     `requests(id, student_id, type, status, created_at, resolved_at)`.
   - 예약/취소/부여는 동시성 때문에 **RPC 함수**로 처리(잔여 횟수 확인 + 삽입을 한 트랜잭션에).
   - 취소 마감(시작 1시간 전)은 서버에서도 다시 검사.
   - RLS: 수강생은 자기 행만 읽기/쓰기, 강사는 전체.
   - `data.js`의 `api` 함수 본문만 `supabase.rpc(...)` 호출로 바꾸면 `app.js`는 그대로 씁니다.
3. **로그인**
   - 지금의 "이름 + 코드"는 시안용입니다. 운영에서는 매직링크나 카카오 로그인을 권하고,
     강사 계정은 이메일 로그인 + `role = instructor`로 구분합니다.
4. **꼭 필요한 것**
   - 강사 모드 인증(지금은 링크만 알면 누구나 열립니다).
   - 예약 확인 / 취소 마감 / 잔여 횟수 알림(카카오 알림톡 또는 메일).
   - 수강권 결제(토스페이먼츠·카카오페이 등)와 결제 후 자동 부여.
5. **콘텐츠**
   - 동작 영상 촬영 후 유튜브 업로드 → `video.youtubeId` 채우기.
   - 수업 사진(스튜디오·클래스 컷)을 히어로나 class 섹션에 추가하면 완성도가 올라갑니다.
