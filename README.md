# 미정 클래스 — 웹사이트 시안 v1

`@mi.jeong_k` 핸드스탠드 · 요가 클래스 사이트의 첫 시안입니다.
망원동 오얏키친 메뉴판에서 가져온 무드(오프화이트 종이 질감, 검정 라인 일러스트,
세로 영문 섹션 타이틀, 넉넉한 여백)에 인스타그램 피드의 버터 옐로우를 포인트로 얹었습니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 구조 + 인라인 SVG 라인 일러스트(sprite) + 영상/강사 모달 |
| `styles.css` | 디자인. 색·타이포·간격은 맨 위 `:root` 변수에서 한 번에 바꿀 수 있습니다 |
| `data.js` | ① 수업·시간표·시퀀스 콘텐츠 ② 예약·수강권 API(localStorage 어댑터) |
| `app.js` | 화면 그리기와 클릭 처리 (데이터는 전부 `api`를 통해서만 다룹니다) |
| `tests/api.test.js` | 예약·취소·강사 대리 예약/취소 로직 테스트 (`node tests/api.test.js`) |

## 보는 방법

1. `index.html`을 브라우저로 열기 (파일 더블클릭).
2. 또는 이 폴더에서 `python -m http.server 8000` → `http://localhost:8000`.

폰트는 Pretendard(CDN) + Instrument Sans(Google Fonts)를 불러옵니다.
인터넷이 없으면 기기 기본 폰트로 보입니다.

## 자주 고칠 곳

- **수업 시간표**: `data.js` → `CLASSES[].slots` (`dow` 0=일 … 6=토, `start`/`end`는 `HH:MM`).
  여기만 고치면 예약 화면의 날짜 목록도 같이 바뀝니다.
  `CLASSES[].mode`는 `offline`(스튜디오) / `online`(온라인). 온라인 클래스는 `slots: []`로 두고
  `when` 문구로 안내합니다(예약 시간표에는 나오지 않음).
- **수업 소개 문구**: `CLASSES[].blurb` / `.note` (현재 문구는 초안입니다).
- **시퀀스**: `WARMUP`, `SEQUENCES.beginner`, `SEQUENCES.intermediate`의 `name` · `dose` · `cue` · `tags`.
- **영상**: 각 동작의 `video.youtubeId`에 유튜브 ID(`dQw4w9WgXcQ` 같은 11자리)를 넣거나,
  `video.url`에 주소(`https://youtu.be/...`)를 넣으면 모달에서 바로 재생됩니다.
  비어 있으면 "영상 준비 중"으로 표시됩니다.
- **수강권 규칙**: `CONFIG.passTypes` (4회권 60일 / 8회권 90일).
- **취소 마감**: `CONFIG.cancelDeadlineMs` (기본 1시간).
- **예약 가능 기간**: `CONFIG.bookingWindowDays` (기본 14일).

## 데모 계정

| 이름 | 코드 | 상태 |
| --- | --- | --- |
| 김하늘 | `MJ-1024` | 신규 (수강권 없음 → `등록`) |
| 이서연 | `MJ-2048` | 4회권 보유, 1회 예약 (3회 남음) |
| 박지우 | `MJ-0812` | 8회권 8/8 소진 + 만료 (→ `재등록`) |
| 정민아 | `MJ-1125` | 8회권 보유, 2회 예약 — 오늘 수업이 취소 마감된 예시 |

예약/수강권 데이터는 `localStorage`(키 `mijeong.class.v1`)에 저장됩니다.
강사 모드 아래 "데모 초기화"로 처음 상태로 되돌릴 수 있습니다.

## 수업 구성

| 수업 | 구분 | 시간 |
| --- | --- | --- |
| 핸드스탠드 무브먼트 | 오프라인 | 90분 · 수·목 14:00–15:30, 토·일 12:00–13:30 |
| 펑셔널 요가 | 오프라인 | 60분 · 일 10:00–11:00 |
| 모닝 모빌리티 | 온라인 | 일정·신청 인스타 DM |
| 핸드스탠드 온라인 코칭 | 온라인 | 개별/정기 진행 · 인스타 DM 신청 |

온라인 두 수업은 정해진 시간표를 지어내지 않고, 카드에 `온라인` 표시와 안내 문구만 두었습니다.
실제 요일·시간·진행 방식이 정해지면 `CLASSES[]`의 `when`을 고치거나 `slots`를 채우면 됩니다.

## 확인해 볼 흐름

1. **신규 등록** — `김하늘` 선택 → `등록` → 강사 모드에서 승인(4회권/8회권) → 잔여 횟수가 생기고 예약 버튼이 열립니다.
2. **재등록** — `박지우` 선택 → `재등록` → 강사 모드 요청 목록에서 `승인 · 개시`.
3. **예약/취소** — `이서연`으로 날짜를 골라 예약 → 잔여 횟수 1 감소 → 같은 자리 `취소`(마감 전)로 횟수 복구.
4. **취소 마감** — `정민아`로 오늘 수업을 보면 "취소 마감"으로 버튼이 잠겨 있습니다.
5. **강사 모드** — 요청 승인, 수강권 부여, 날짜별 예약 현황(수업별 예약자 이름).
6. **강사 대리 예약·취소** — 강사 모드 → `대리 예약`에서 수강생과 수업을 골라 예약하면
   수강생 잔여 횟수가 1회 줄고 화면에 바로 반영됩니다. `예약 현황`의 예약 옆 `취소`는
   수강생의 1시간 전 마감과 상관없이 취소되고(마감 후 예약에는 `취소 마감` 표시),
   잔여 횟수 1회가 복구됩니다.

## 아직 정해지지 않아 가정한 부분

- 취소하면 **횟수가 복구**됩니다(마감 전 취소 기준). 강사 모드의 대리 취소는
  마감과 상관없이 취소되고 횟수가 복구되지만, 이미 시작한 수업은 예약할 수 없습니다.
- 수강권을 새로 부여하면 이전 수강권은 **교체**되고 잔여 횟수는 넘어가지 않습니다
  (이미 잡힌 예약은 새 수강권에서 소진으로 계산).
- 수업 소개 문구와 큐잉 문구는 시안용 초안입니다. 실제 수업 언어로 바꿔 주세요.
- 수업 정원(자리 수) 개념은 아직 없습니다.

## 실제 운영 배포까지

1. **호스팅 (GitHub Pages)**
   - 이 폴더를 저장소에 올리고 Settings → Pages에서 배포, 또는 `gh-pages` 브랜치 사용.
   - 커스텀 도메인(`mijeong.com` 등) 연결 + HTTPS.
2. **백엔드 (Supabase 권장)**
   - 테이블: `students(id, name, code, created_at)`,
     `passes(id, student_id, type, total, used, issued_at, expires_at)`,
     `sessions(id, class_id, starts_at, ends_at)`,
     `bookings(id, student_id, session_id, created_at, status)`,
     `requests(id, student_id, type, status, created_at, resolved_at)`.
   - 예약/취소/부여는 동시성 때문에 **RPC 함수**로 처리(잔여 횟수 확인 + 삽입을 한 트랜잭션에).
   - 취소 마감(시작 1시간 전)은 서버에서도 다시 검사.
   - RLS: 수강생은 자기 행만 읽기/쓰기, 강사는 전체.
   - `data.js`의 `api` 함수 본문만 `supabase.rpc(...)` 호출로 바꾸면 `app.js`는 그대로 씁니다.
3. **로그인**
   - 지금의 "이름 + 코드"는 시안용입니다. 운영에서는 매직링크나 카카오 로그인을 권하고,
     강사 계정은 이메일 로그인 + `role = instructor`로 구분합니다.
4. **꼭 필요한 것**
   - 강사 모드 인증(지금은 링크만 알면 누구나 열립니다).
   - 예약 확인 / 취소 마감 / 잔여 횟수 알림(카카오 알림톡 또는 메일).
   - 수강권 결제(토스페이먼츠·카카오페이 등)와 결제 후 자동 부여.
5. **콘텐츠**
   - 동작 영상 촬영 후 유튜브 업로드 → `video.youtubeId` 채우기.
   - 수업 사진(스튜디오·클래스 컷)을 히어로나 class 섹션에 추가하면 완성도가 올라갑니다.
